客户流失逻辑回归分析

主要结论

完成图片中的 12 项作业。40,000 条记录中，20,522 条为流失客户（51.31%）；共 104 个缺失单元格，分布在 101 条记录中。流失客户平均年龄 39.80，未流失客户 49.51；平均 tot_bill 分别为 146.51 和 102.31，差值 44.20，95% 置信区间为 43.64–44.75。Welch 双侧 t 检验 p<0.001，Cohen's d=1.58；程序中的 p=0 是数值下溢，不能解释为概率严格为零。数据未说明账单的货币单位或观察期。

方法与验证

churn_flag 对应作业里的 churn，1 表示流失。排除唯一客户编号 cust_id。按目标分层划分 32,000 条训练记录和 8,000 条验证记录，随机种子 42。数字变量用训练中位数填补，类别变量用训练众数填补；每个交叉验证折内重新拟合填补、编码与变换，避免泄漏。home_owner 按类别处理，其他计数变量按数值处理。基础模型使用标准化、独热编码和 L2 正则化逻辑回归。

仅在训练集上进行 5 折交叉验证，比较基础模型、Yeo-Johnson 变换和年龄/账单二次项与交互项。根据平均 CV ROC AUC 选择 age_bill_quadratic，验证集不参与模型或阈值选择。三个方案的 CV AUC 分别为 0.9494、0.9497、0.9506。

验证集结果

ROC AUC=0.9525，95% bootstrap 区间 [0.9474, 0.9576]；precision=0.9432，recall=0.9274，F1=0.9353，accuracy=0.9341，AP=0.9377。正类为流失，分类阈值为 0.5。混淆矩阵：TN=3667、FP=229、FN=298、TP=3806。AP 是 PR 曲线的平均精确率指标，与 ROC AUC 不同。

二次变换的 CV AUC 比基础模型高 0.00115，验证 AUC 高 0.00132；但验证 F1 为 0.9353，基础模型为 0.9356。因此，变换对概率排序略有改善，并未提高默认阈值下的所有分类指标。

结果解释与局限

基础模型中，控制其他变量后，yahoo_air 每增加一个训练标准差对应的流失 odds 约为原来的 2.07 倍，age 每增加一个标准差约为 0.53 倍。odds 变化不等于流失概率的百分点变化。所选二次模型的年龄与账单效应取决于客户取值及交互项，不能用单一恒定 odds ratio 概括。总量和组成变量可能相关，系数不能解释为因果效应或显著性检验。

这是模拟数据。当前结果来自一次独立的验证划分，没有额外第三个测试集，也没有证明真实客户或未来时段的表现。若要用于业务，应另外做时间外验证，并根据留存成本在训练数据中选择阈值。下面附完整英文报告、各折比较、图表及方法细节。

Customer churn: logistic regression analysis

Findings The model selected using training-only cross-validation was **age_bill_quadratic**. On the 8,000-customer validation set, ROC AUC was **0.9525** (300-resample percentile bootstrap 95% CI 0.9474–0.9576), precision **0.9432**, recall **0.9274**, and F1 **0.9353** at probability threshold 0.5. Average precision (AP) was **0.9377**, compared with validation churn prevalence 0.5130. AP summarizes the precision-recall curve and is distinct from ROC AUC.

Welch's two-sided independent-samples t-test compares observed tot_bill values without imputation. H0: the two population means are equal. Retained customers: n=19,466, mean=102.3140; churned customers: n=20,501, mean=146.5104. Churn-minus-retained difference=44.1964, 95% CI [43.6431, 44.7497], t=156.5685, df=36942.17, p < 0.001 (the computed p-value underflows to 0; it is not literally zero), Cohen's d=1.5765. Reject H0 at alpha=0.05. The difference is large relative to within-group variation. This is an unadjusted association, with customer independence assumed. Complete-case inference may be biased if missing bills are not missing at random; statistical significance alone does not establish practical importance or causation.

Conclusion and reproducibility (task 12) This is a mock-data exercise. Generalization to real customers, future time periods, or other acquisition channels has not been established. The held-out validation set provides the requested out-of-sample performance check; it is not an additional third test set. Production evaluation would require a future-time sample and a threshold chosen from training data according to retention costs. The AUC bootstrap interval captures validation sampling variability conditional on the fitted model, not retraining or model-selection uncertainty.
